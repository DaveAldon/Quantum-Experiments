# Quantum-Experiments

A project for exploring quantum computing with Qiskit.

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the sample code:
```bash
python fast_search.py
```

## What's included

- `fast_search.py`: Implementation of Grover's algorithm for searching a mock database
- `requirements.txt`: Python dependencies for Qiskit development
